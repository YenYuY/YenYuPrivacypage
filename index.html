Yen PDF Viewer Chrome 擴充功能

隱私權政策

最後更新：2026 年 8 月 27 日

Yen PDF Viewer 是一款在 Chrome 瀏覽器內識別、開啟與顯示 PDF 的擴充功能。PDF 內容和密碼只在使用者的裝置上處理，不會上傳給開發者或第三方伺服器。

處理的資料

Yen PDF Viewer 僅為了提供 PDF 閱讀功能，在使用者裝置上處理下列資料：

  • PDF 網址、主要分頁導覽事件，以及用於判斷檔案是否為內嵌 PDF 的 Content-Type 與 Content-Disposition 回應標頭。
  • 使用者開啟的網路 PDF 內容。
  • 使用者主動選擇或拖放的本機 PDF 內容。
  • 使用者為受密碼保護 PDF 輸入的密碼。密碼僅在當次閱讀期間的記憶體內用於本機解密，不會儲存或傳送。
  • 使用者的介面主題與「自動接管 PDF」開關偏好。這些設定只儲存於 Chrome 的擴充功能本機儲存空間。

資料用途

上述資料僅用於：

  • 識別使用者正在開啟的 PDF。
  • 在使用者的瀏覽器內下載、解析、顯示、搜尋、列印或儲存 PDF。
  • 保留使用者選擇的介面主題與自動接管開關。

本機處理、儲存與保留期間

PDF 內容與 PDF 密碼只在使用者的裝置上處理。開發者沒有提供用於上傳、分析或儲存 PDF、PDF 密碼、瀏覽紀錄或使用行為的伺服器。

PDF 與密碼不會由擴充功能永久保留。主題與功能開關設定會留在 Chrome 本機儲存，直到使用者變更設定、清除擴充功能資料或移除擴充功能。

開啟網路 PDF 時，擴充功能會直接連線至使用者指定或正在瀏覽的 PDF 原始網站以取得文件。該原始網站可能按照自身的隱私權政策處理標準網路請求資訊，例如 IP 位址與伺服器日誌。

資料分享與販售

Yen PDF Viewer 不會將使用者資料傳送給開發者，不會販售使用者資料，也不會為廣告、個人化、信用評等、貸款或其他與 PDF 閱讀功能無關的目的使用或轉移使用者資料。

Chrome Web Store 限制使用聲明

本擴充功能對資訊的使用依循 Chrome Web Store 使用者資料政策，包括限制使用要求。使用者資料僅為 Yen PDF Viewer 已公開說明的單一用途與使用者可見功能而處理。

使用者選擇與刪除

使用者可隨時在閱讀器內關閉「自動接管 PDF」，也可透過 Chrome 的擴充功能管理頁面限制網站或本機檔案存取權限。移除擴充功能或清除其網站資料後，本機儲存的偏好設定會一併刪除。

政策變更

如果 Yen PDF Viewer 的資料處理實務改變，本政策將同步更新，並依 Chrome Web Store 規定向使用者顯著揭露。
